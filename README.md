# studyGuide4Taty
A web app to help Tatyana study

# How to install
Prerequisite:
Install Python: https://www.python.org/downloads/
If using a Windows machine, you will need to setup the Environment Variables to make sure your can run Python commands from any folder.

After downloading and unzipping, if necessary, open the CLI (run cmd). Navigate to the folder path you placed this application (cd "folder path" ex: "C:\Study Guide Game".
Run this command: "python server.py"
